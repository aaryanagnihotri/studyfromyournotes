Artificial Intelligence Study Notes

Machine learning is a field of artificial intelligence that enables computer systems to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

Supervised learning uses labelled training examples. Classification predicts categories, such as spam or not spam. Regression predicts continuous numerical values, such as house prices.

Unsupervised learning works with data that has no labelled target. Clustering groups similar data points, while dimensionality reduction represents data using fewer features.

A neural network is made of interconnected computational units called neurons. A typical feed-forward network contains an input layer, one or more hidden layers, and an output layer. Training adjusts weights to reduce a loss function.

A retrieval augmented generation system first retrieves relevant passages from a knowledge source and then gives those passages to a language model as context. Grounding answers in retrieved documents can reduce unsupported responses. Citations help users verify the evidence.

Azure AI Search is a cloud search service that can index and retrieve content. Azure Blob Storage stores unstructured files such as PDFs. Microsoft Foundry provides a platform to build, deploy, and manage AI applications and model endpoints.
